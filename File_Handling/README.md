# File Handling

This folder contains programs related to Python file operations.

## Topics Covered

* Opening and Closing Files
* File Modes (`r`, `w`, `a`, `r+`, `w+`, `a+`)
* Counting Words in a File
* Counting Characters
* Counting Vowels
* Counting Alphabets, Digits and Special Characters
* Reading Text Files

## Learning Outcomes

* Understand how files are accessed in Python.
* Learn to process text data stored in files.
* Practice common file-handling interview and practical questions.
